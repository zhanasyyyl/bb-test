Help

Zoom and Magnification

To zoom in or out, press Control + Plus (+) or Control + Minus (-) (Command on a Mac). Press Control + 0 to go back to 100%.

On a touchscreen or touchpad, pinch in or out.

Your device's own magnifier also works during the test:

  • Windows: Magnifier, Windows logo key + Plus (+)
  • Mac: Zoom, Option + Command + 8 (turn it on in System Settings > Accessibility > Zoom)
  • Chromebook: full-screen magnifier, Search + Ctrl + M
In-App Calculator

On math questions, select Calculator at the top right to open a built-in calculator. Switch between Graphing and Scientific at its top.

Drag the calculator's top bar to move it and its bottom-right corner to resize it. You may also use your own approved calculator.

Testing Timers

The timer at the top shows how much time is left in the current module. Select Hide to hide it and Show to bring it back. You'll see a message when 5 minutes are left.

When time runs out, the module ends and you move on automatically. After the Reading and Writing section there's a 10-minute break.

Highlights & Notes

Select Highlights & Notes at the top right, then select text in the passage or question to highlight it.

  • Select a highlight to change its color, add an underline, add a note or delete it.
  • Notes appear beside the passage and stay with that question.
  • Highlights and notes aren't scored.
Line Reader

Select More > Line Reader to show a reading band that helps you focus on a few lines at a time.

  • Drag the six dots at the top to move it, or select the six dots and use the up and down arrow keys.
  • Drag the arrow below the band to show more or fewer lines.
  • Use the expand button to stretch it across the screen.
Option Eliminator

On multiple-choice questions, select the ABC button above the answer choices to turn on option eliminator mode. Then select the crossed-out letter next to any choice you think is wrong. Select Undo to bring it back. A crossed-out choice can't be selected.

Mark for Review

Select Mark for Review next to the question number to flag a question you want to come back to. Flagged questions are marked in the question menu and on the review page.

Question Menu

Select Question X of Y at the bottom of the screen to see every question in the module: which you've answered and which you've marked for review. Select a number to go to that question, or select Go to Review Page.

Make an Educated Guess

There's no penalty for wrong answers, but a blank answer can't earn credit. If you're stuck, rule out the choices you can and guess rather than leave a question blank.

Restarting the App

Your answers are kept only in this browser window. Don't refresh the page or close the tab during the test: if you do, the test starts again from the beginning.

Submitting Your Answers

When the timer for the last module reaches zero, the test ends and you're taken to the finish screen. If your device is offline at that moment, you'll see a Reconnect to Finish message; reconnect and it finishes automatically.

Screen Readers

Start your device's screen reader before you begin:

  • Windows: Narrator, Windows logo key + Ctrl + Enter
  • Mac: VoiceOver, Command + F5
  • iPad: VoiceOver, in Settings > Accessibility > VoiceOver
  • Chromebook: ChromeVox, Ctrl + Alt + Z
Screen Magnification

Screen magnifiers built into your device, or approved third-party tools, work with the test. See Zoom and Magnification above for the built-in options.

{# ===== Assistive Technology ===== #}

Assistive Technology

Assistive Technology

The assistive technology you use everywhere else (screen readers, magnifiers, dictation, braille displays) also works here, because the test runs in your web browser.

Turn on and set up any assistive technology before you start the test, so you don't lose testing time.

Text to Speech

This practice test doesn't have its own read-aloud tool. To hear passages and questions, use your device's screen reader (see Screen Readers below).

Speech-to-Text

Use your device's dictation to type answers by voice:

  • Windows: voice typing, Windows logo key + H
  • Mac: Dictation, press the Microphone key or turn it on in System Settings > Keyboard
  • Chromebook: dictation, Search + D
Screen Readers
  • Windows: Narrator, Windows logo key + Ctrl + Enter
  • Mac: VoiceOver, Command + F5
  • iPad: VoiceOver, in Settings > Accessibility > VoiceOver
  • Chromebook: ChromeVox, Ctrl + Alt + Z

Use Tab and the arrow keys to move between answer choices and buttons. See More > Shortcuts for the test's keyboard shortcuts.

Zoom and Magnification

Press Control + Plus (+) or Control + Minus (-) to zoom (Command on a Mac) and Control + 0 to reset. Your device's magnifier also works: Windows Magnifier (Windows logo key + Plus (+)), Mac Zoom (Option + Command + 8) or the Chromebook magnifier (Search + Ctrl + M).

Refreshable Braille Displays

A refreshable braille display connected to your screen reader shows the test's text. Set it up and test it with your screen reader before you begin.

{# ===== Exit the Exam ===== #}

Are You Sure You Want to Exit the Test?

Practice tests are not scored, and your progress isn't saved. If you exit and come back, you'll start over.
